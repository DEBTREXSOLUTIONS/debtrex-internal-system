DEBTREX MOBILE-FRIENDLY UPDATE
================================

WHAT CHANGED
============
The whole frontend now works well on phones (down to 320px wide).

KEY IMPROVEMENTS:

1. SIDEBAR (components/Sidebar.tsx)
   - Desktop (>=1024px): always visible on the left, exactly like before
   - Mobile/Tablet (<1024px): hidden by default, opens as a slide-in drawer
     when you tap the hamburger button (top-left corner)
   - Tap outside the drawer or any nav link to close it
   - Body scroll locks while drawer is open

2. TOP BAR (components/TopBar.tsx)
   - Page title left-padded on mobile to clear the hamburger button
   - Search box only shows on desktop (it was overflowing on small screens)
   - Notification bell stays visible everywhere

3. GLOBAL STYLES (app/globals.css)
   - Buttons: 42px minimum height = comfortable to tap with a thumb
   - Inputs: 16px font on mobile (prevents iOS auto-zoom on focus)
   - Body has overflow-x: hidden as a safety net against rogue overflow
   - New .no-scrollbar utility for hiding scroll indicators on tab strips

4. RESPONSIVE PAGE PADDING
   - All pages: p-6 -> p-4 sm:p-6 (less padding on small screens, more space for content)

5. TABLES (Team, Budget all-expenses, Budget allocations)
   - Wrapped in horizontal scroll containers with min-widths
   - Users see they can swipe-scroll to see more columns
   - Headers stack vertically on mobile so action buttons don't overlap titles

6. TASK DETAIL PAGE
   - Title shrinks from 3xl to 2xl on mobile
   - break-words prevents long task titles from breaking the layout

7. CALENDAR
   - FullCalendar toolbar wraps to multiple lines on small screens
   - Smaller buttons and title fonts
   - Horizontal scroll if month grid is too wide

8. TASKS LIST
   - Filter tabs (Mine / Created / All) scroll horizontally if they don't fit
   - "New Task" button stacks below tabs on mobile

9. LOGIN PAGE
   - No changes needed -- already mobile-friendly (red brand panel hidden below 1024px)

Then:
  1. Stop dev server (Ctrl+C if running)
  2. npm run dev
  3. Test in Chrome on desktop -- should look identical to before
  4. Open Chrome DevTools (F12), click the device toolbar icon
     (or press Ctrl+Shift+M), pick "iPhone 14" or similar
  5. Browse around -- everything should work with thumb taps

PUSH TO PRODUCTION
==================

  git push

Vercel auto-deploys. After ~2 min your team can use the system from their phones.
