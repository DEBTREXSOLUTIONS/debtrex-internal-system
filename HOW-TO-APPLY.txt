DEBTREX — CUSTOM ROLES + PIPELINE COLLABORATORS + PERF + SIDEBAR
=================================================================

WHAT'S IN THIS PATCH
====================

1. CUSTOM ROLES — Add your own roles beyond CEO/Manager/Employee
   - Sidebar → Admin → Custom Roles
   - Create roles like "Senior Agent", "Closer", "Lead Specialist"
   - Each role gets its own column on the Permissions page
   - Built-in roles can't be edited or deleted (CEO, Owner, etc.)
   - Roles with assigned users can't be deleted

2. PIPELINE COLLABORATORS — Add team members to any contact
   - On any contact's detail page, click the new "Team" tab
   - Click "Add Team Member" to add managers/owners/anyone to that contact
   - Two access levels: Collaborator (edit) or Observer (read-only)
   - Collaborators show up on the contact card and can do everything
     the assigned agent can do
   - The contact owner can't be removed (change assignment first)

3. GROUPED SIDEBAR — Sections instead of one long list
   - Home: Dashboard, Tasks, Calendar, Files
   - Pipeline: Sales, Management
   - Tools: Calculators
   - Team: Performance, Team Members, Twilio Numbers
   - Financial: Budget
   - Admin: Permissions, Custom Roles
   - Click any section header to collapse it

4. PERFORMANCE FIXES — Site should feel noticeably snappier
   - getCurrentUser cached per request (was running 2-3x per page)
   - Pipeline pages fetch permissions in parallel (was sequential)
   - Permission cache extended from 1 min to 5 min
   - lucide-react / fullcalendar / recharts auto tree-shaken
   - Static assets cached aggressively
   - Sidebar memoized to prevent re-renders

CUSTOM ROLES — HOW THEY WORK
==============================

When you create a custom role like "Senior Agent":
  1. Role gets added to custom_roles table
  2. Permissions get seeded for it (all OFF by default)
  3. Role appears as a new column on /permissions
  4. You toggle which permissions it has (e.g. pipeline.create, call.make)
  5. Save changes on the Permissions page
  6. Now you can assign that role to team members on /team

To delete a role: first reassign anyone who has it, then delete.


PIPELINE COLLABORATORS — HOW THEY WORK
========================================

Think of it like adding co-workers to a Google Doc:
  - "Owner" = the assigned_to person (one per contact)
  - "Collaborator" = full access, multiple allowed
  - "Observer" = read-only, multiple allowed

When a CEO/Owner/manager wants to put themselves on a contact's pipeline:
  - Open the contact
  - Click "Team" tab
  - Click "Add Team Member"
  - Pick themselves or other team members
  - Choose access level

Anyone added becomes able to call, log, edit, and add notes on
the contact — but only the original owner can be reassigned via Edit.

Requires: pipeline.assign_to_anyone permission (default: leadership + managers).


PERFORMANCE NOTES
==================

After applying this patch, expect:
  - Initial page load: ~30-40% faster (parallel perm checks)
  - Navigation between pages: ~50% faster (cached user lookup)
  - Sidebar: instant render (memoized, no longer re-renders on each nav)

If still slow, the bottleneck is probably:
  - Supabase database location (US East fastest from US, slowest from Europe/Asia)
  - Vercel region (set to "iad1" or closest to your Supabase region)
  - Slow internet connection on user end
  - First load only (Next.js compiles on-demand in dev)

Production builds (after git push) are 3-5x faster than dev mode.


TROUBLESHOOTING
===============

"Custom role I created doesn't show in permissions"
  → Refresh the /permissions page (the matrix data is fetched at render time)

"Can't delete a role"
  → Some user still has that role. Go to /team, change their role to something else.

"Team tab doesn't show on contact pages"
  → Make sure migration-005 ran (pipeline_collaborators table exists)

"Can't add team members"
  → You need pipeline.assign_to_anyone permission. Default is leadership+managers.
