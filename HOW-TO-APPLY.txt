DEBTREX TWILIO UPDATE — PAID ACCOUNT OPTIMIZATIONS
=====================================================

WHAT CHANGED
============

Since you have a funded Twilio account (not trial), this patch
upgrades the integration to use paid-account features:

1. Answering Machine Detection (AMD)
   - Twilio detects voicemail vs human automatically
   - Voicemails auto-marked in your call log
   - Saves agent time, no need to manually log "left voicemail"

2. Dual-channel call recording
   - Agent and lead recorded on separate audio tracks
   - Easier to review, transcribe, and train on

3. Better compliance built-in
   - Recording disclosure now played to both parties
     ("This call may be recorded for quality and training purposes")
   - Required for two-party-consent states (CA, FL, IL, MD, MA, etc.)

4. answerOnBridge="true"
   - Billing only starts when the lead actually picks up
   - Saves money on no-answer calls

5. Optional custom caller ID
   - New env var TWILIO_CALLER_ID lets you display a different number
     than your purchased one (useful when you buy regional numbers
     for better answer rates)

6. New webhook for AMD results: /api/twilio/amd

WHAT YOU GET TO TURN ON LATER (covered in the guide)
=====================================================

- CNAM branded caller ID ("DEBTREX SOLUTIONS" instead of just a number)
- STIR/SHAKEN attestation (already active on paid accounts)
- Caller ID by region (regional numbers for better answer rates)

NEW OPTIONAL ENV VARS
=====================

Add these to .env.local AND Vercel if you want to use them:

  # Optional: display a different caller ID than TWILIO_PHONE_NUMBER
  TWILIO_CALLER_ID=
  
  # Optional: set to "false" to disable AMD (saves $0.0075/call)
  # Default: enabled (recommended for paid accounts)
  TWILIO_ENABLE_AMD=true

The required vars haven't changed:
  TWILIO_ACCOUNT_SID
  TWILIO_AUTH_TOKEN
  TWILIO_PHONE_NUMBER


STEPS
=====

1. Drop the 4 files into your project (preserving folder structure)
2. Stop dev server (Ctrl+C)
3. npm run dev
4. Test a call as before:
   - Open a contact
   - Click Call Now
   - Pick up your phone
   - Listen for "Connecting your call. This call may be recorded..."
   - Talk to the lead
   - End call
   - Check Call Log tab — recording should appear within 1-2 min

5. Push to production:
   git add .
   git commit -m "Upgrade Twilio for paid account features"
   git push


VERIFICATION
============

After the test call, check Twilio Console → Monitor → Logs → Calls
You should see:
  - Two call legs (one to agent, one to lead)
  - Both with status "completed"
  - Recording link
  - For paid accounts: STIR/SHAKEN attestation level (A is best)
  - Total cost shown per call

COMMON QUESTIONS
================

Q: Do I have to set TWILIO_CALLER_ID?
A: No. If empty, the system uses TWILIO_PHONE_NUMBER as caller ID.
   Only useful if you buy multiple numbers.

Q: Should I keep AMD enabled?
A: Yes. The cost is $0.0075 per call and it gives you cleaner data.
   Disable only if budget is extremely tight.

Q: Do I need CNAM?
A: Optional. Helps answer rates on landlines (~5-10% bump). Less
   effective on mobile carriers. Costs $0.50/month/number.

Q: My calls were already working — will this break anything?
A: No. The integration is backward compatible. AMD is additive,
   caller ID falls back to your existing number, recording just
   gains the dual-channel improvement. Existing calls in your log
   stay as they were.
