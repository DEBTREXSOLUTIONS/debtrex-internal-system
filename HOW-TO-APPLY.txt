DEBTREX FEATURES UPDATE — Pipeline + Permissions + Twilio
=============================================================

WHAT'S NEW
==========

1. PIPELINE — MANAGEMENT (B2B)
   - /pipeline/management
   - Companies to call to make deals with, sign contracts with
   - Track: company name, industry, deal value, contact person, status
   - Statuses: New → Contacted → Meeting → Negotiating → Contract Sent
     → Closed Won / Closed Lost

2. PIPELINE — SALES (B2C)
   - /pipeline/sales
   - Leads to pitch the debt relief program
   - Track: lead name, estimated debt, monthly income, status
   - Statuses: New Lead → Contacted → Qualified → Proposal Sent
     → Enrolled / Not Interested / Unreachable

3. EVERY CONTACT HAS:
   - Click-to-call button (Twilio integration — see Part 5)
   - Manual call log (date, direction, outcome, duration, notes)
   - Notes panel (sticky pin, multi-user, edit own notes)
   - Status changer (one-click status moves)
   - Edit form (full contact details, address, phone, etc)
   - Assignment (who's working this contact)
   - Delete

4. GRANULAR PERMISSIONS SYSTEM
   - /permissions (visible only to CEO/Owner)
   - Toggle ANY permission for ANY role:
     * Section visibility (10 sections)
     * Tasks: create, edit, delete, view all, assign to anyone
     * Events: create, edit, delete, invite anyone
     * Budget: view, edit allocations, submit/approve expenses
     * Team: invite, change roles, deactivate, delete
     * Performance: view all, view team, assign managers
     * Pipeline: create, edit, delete, view all, assign, export
     * Calls: log, make (Twilio), view all
     * Permissions admin (locked ON for CEO/Owner)
   - Quick "all on / all off" buttons per group + role
   - Save bar appears when changes pending
   - Cache invalidates on save — changes apply within 1 minute

5. TWILIO CLICK-TO-CALL
   - On any contact's page, click "Call Now"
   - Twilio rings the agent's phone first, bridges to the lead
   - Auto-records the call
   - Logs duration, outcome (connected/no-answer/voicemail/etc)
   - Recording appears as playable audio in the call log
   - SEE: DEBTREX-Twilio-Setup-Guide.docx for FULL SETUP


HOW TO APPLY
============

STEP 1 — RUN THE DATABASE MIGRATION (CRITICAL)

  1. Open Supabase → SQL Editor → New query
  2. Copy the entire contents of database/migration-003.sql
  3. Paste into the editor
  4. Click "Run"
  5. Verify: Table Editor should now show 4 new tables:
     - pipeline_contacts
     - call_logs
     - contact_notes
     - role_permissions  (auto-seeded with default permissions)

STEP 3 — RESTART AND TEST

  npm run dev

  - Sign in as CEO
  - Sidebar should show new sections: Management, Sales, Permissions
  - Click Permissions → see the toggle matrix
  - Click Management → click "Add Contact" → create a test company
  - Click Sales → create a test lead
  - Open the lead → try Edit, change Status, add a Note, Log a Call

STEP 4 — TWILIO (OPTIONAL BUT POWERFUL)

The pipeline works WITHOUT Twilio — agents can manually log calls.
To enable click-to-call:
  - Read DEBTREX-Twilio-Setup-Guide.docx
  - Sign up at twilio.com
  - Buy a phone number
  - Add 3 env vars to .env.local AND Vercel:
      TWILIO_ACCOUNT_SID
      TWILIO_AUTH_TOKEN
      TWILIO_PHONE_NUMBER
  - Configure webhook URLs (covered in the guide)
  - Each agent must add their phone number in Settings → Profile

STEP 5 — PUSH TO PRODUCTION

  git add .
  git commit -m "Add pipeline, permissions, twilio integration"
  git push

  Vercel auto-deploys.


NOTES
=====

NO new dependencies — uses native fetch for Twilio API
NO breaking changes to existing pages/data
Default permissions seed sensibly (CEO=all, Manager=most, etc)

The permission cache lives in-memory for 1 minute, so when you flip
a toggle, it can take up to 1 minute to take effect for active users.
The cache invalidates immediately for the user who made the change.

TROUBLESHOOTING
===============

"Module not found 'lib/permissions'" → make sure file is at lib/permissions.ts
                                       (lowercase, exact path)

"relation 'pipeline_contacts' does not exist" → migration-003.sql wasn't run

"Twilio not configured" → env vars missing or server not restarted

"You have no phone number on file" → Settings → Profile → Phone

Page works in dev but not Vercel → environment variables didn't sync
                                    Vercel → Settings → Environment Variables
                                    add TWILIO_* vars, redeploy
