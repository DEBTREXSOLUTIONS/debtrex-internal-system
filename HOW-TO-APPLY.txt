DEBTREX FEATURES UPDATE — Performance + Calculators
======================================================

WHAT'S NEW
==========

1. PERFORMANCE TRACKING (/performance)
   - CEO/Owner/Co-Owner: see EVERYONE's performance — task counts, hours,
     overdue tasks, on-time completion rate, last activity
   - Managers: see ONLY their assigned agents' performance
   - Sortable table with KPI summary at the top
   - Search bar to find specific people
   - Top-3 trophy icons when sorted by completed tasks

2. MANAGER ASSIGNMENTS (/performance/assignments)
   - VISIBLE ONLY to CEO/Owner/Co-Owner
   - Pick a manager, select multiple agents, click "Assign agents"
   - Many-to-many: one agent can report to multiple managers if needed
   - Shows unassigned employees as a warning at the top
   - Easy remove with one click

3. CLIENT CALCULATORS (/calculators)
   Three tabs:
   a) DTI RATIO — Debt-to-Income calculator with color-coded categories
      (Excellent/Good/Concerning/High Risk/Critical) and reference scale
   b) BUDGET CALCULATOR — Full client budget with line-item expenses and
      debts. Auto-recommends a debt relief program based on debt ratio:
        - Self-Pay if debt ratio < 20%
        - Debt Management Plan if 20-35%
        - Debt Consolidation if 35-50%
        - Debt Settlement if 50%+
      Estimates monthly payment and savings
   c) HISTORY — All calculations you've saved, with enrollment status
      tracking (prospect → qualified → enrolled / declined / closed)

   Available to: CEO, Owner, Co-Owner, Manager, Employee, Accountant
   Hidden from: Viewer

4. SIDEBAR UPDATES
   - "Calculators" link visible to most roles
   - "Performance" link visible to leadership and managers
   - "Manager Assignments" sub-link appears under Performance when
     leadership is on a Performance page

DATABASE MIGRATION REQUIRED
============================
You MUST run database/migration-002.sql before using these features.

1. Open Supabase dashboard
2. Click "SQL Editor"
3. Click "New query"
4. Paste the entire contents of database/migration-002.sql
5. Click "Run"
6. Verify by visiting Table Editor — you should see two new tables:
   - manager_assignments
   - client_calculations

QUICK TOUR (After Setup)
========================

CEO/Owner/Co-Owner workflow:
1. Sign in
2. Sidebar -> Performance -> see everyone
3. Click "Manager Assignments" sub-link
4. Pick a manager (e.g. Sarah) -> select agents (e.g. Mike, Jane)
   -> click "Assign agents"
5. Sarah now sees Mike and Jane only on her Performance page

Agent (Employee) workflow:
1. Sign in
2. Sidebar -> Calculators
3. Tab: DTI Ratio
   - Enter monthly income: $5000
   - Enter monthly debts: $2200
   - Result: 44% (High Risk) — strong candidate for debt settlement
4. Tab: Budget Calculator
   - Enter income, expenses, debts line by line
   - System recommends a program and estimates monthly payment
5. Save with client name to keep history

Manager workflow:
1. Sign in
2. Sidebar -> Performance -> see ONLY assigned agents
3. Sort by On-Time rate or Overdue count
4. Use Calculators just like agents do
