DEBTREX — BROWSER-BASED CALLING (TWILIO VOICE SDK)
====================================================

WHAT CHANGES
============

OLD: Click Call Now → your personal phone rings → you pick up →
     Twilio bridges to lead → talk on your phone.
     
NEW: Click Call Now → browser asks for mic permission → full-screen
     dialer opens → lead's phone rings → talk through your computer
     mic/speakers. No personal phone needed.

The lead still sees your Twilio number as caller ID. Everything else
(recording, call logs, status tracking) works the same.


READ THE GUIDE FIRST
====================

  DEBTREX-Browser-Calling-Setup-Guide.docx

It walks through the 15-minute Twilio setup (API Key + TwiML App).
You MUST complete that setup before this patch works.


WHAT YOU NEED FROM TWILIO (3 new things)
=========================================

  TWILIO_API_KEY        (starts with SK...)
  TWILIO_API_SECRET     (long random string)
  TWILIO_TWIML_APP_SID  (starts with AP...)

Steps to create them are in Sections 2 and 3 of the setup guide.
Takes about 15 minutes total in the Twilio Console.


HOW TO APPLY THE CODE
======================

STEP 1 — UPDATE PACKAGE.JSON AND INSTALL DEPENDENCIES

  Replace your package.json with the one in this patch.
  Then run:
    npm install
  
  This adds two new packages:
    - twilio (server SDK, for token generation)
    - @twilio/voice-sdk (browser SDK, for in-browser calling)

STEP 2 — DROP IN THE FILES (9 files)

  package.json                                       [REPLACE]
  middleware.ts                                      [REPLACE]
  .env.example                                       [REPLACE]
  lib/twilio-voice.ts                                [NEW]
  components/BrowserDialer.tsx                       [NEW]
  app/pipeline/ContactDetail.tsx                     [REPLACE]
  app/api/twilio/voice-token/route.ts                [NEW]
  app/api/twilio/voice-twiml/route.ts                [NEW]
  app/api/twilio/log-browser-call/route.ts           [NEW]

STEP 3 — ADD ENV VARS

  Local (.env.local):
    TWILIO_API_KEY=SK...
    TWILIO_API_SECRET=...
    TWILIO_TWIML_APP_SID=AP...

  Vercel (Settings → Environment Variables):
    Add all 3 — check ALL THREE environment boxes (Production, Preview, Development)
    Save each
    REDEPLOY (Deployments → ⋯ → Redeploy)

STEP 4 — CONFIGURE TWIML APP IN TWILIO CONSOLE

  Console → Voice → Manage → TwiML Apps → your DEBTREX app
  Set Request URL to:
    https://debtrex-internal-system.vercel.app/api/twilio/voice-twiml
  Save

STEP 5 — TEST

  Sign in to DEBTREX
  Open any contact in /pipeline/sales
  Click Call Now
  When browser asks for mic permission, click Allow
  Full-screen dialer opens
  Lead's phone rings within 2-3 seconds
  Talk through your computer
  Click Hang Up when done

STEP 6 — PUSH TO PRODUCTION

  git add .
  git commit -m "Add Twilio Voice SDK browser calling"
  git push


THE OLD CODE STILL WORKS
========================

The old phone-bridge endpoints (/api/twilio/call, /api/twilio/twiml/dial)
are still in the codebase. They're not used by the Call Now button
anymore, but if you want to switch back, you can revert ContactDetail.tsx.

If you don't want them at all, you can delete:
  app/api/twilio/call/
  app/api/twilio/twiml/

But leaving them doesn't hurt.


WHAT AGENTS NEED ON THEIR END
=============================

- A modern Chrome / Edge / Firefox browser
- A working microphone (built-in or USB)
- Microphone permission granted to the DEBTREX site (one-time)
- That's it. No personal phone. No app to install.


COSTS
=====

Browser calling costs the SAME as phone bridging:
  ~$0.014 per minute outbound (US)
  ~$0.0025 per minute recording
  
The Voice SDK itself is free. Only call minutes cost money.


TROUBLESHOOTING (also in the guide)
====================================

"Voice SDK not configured" → env vars missing on Vercel, redeploy
"Initializing forever" → mic permission denied; check lock icon
"Ringing but lead never rings" → TwiML App Request URL wrong
"Call connects but no audio" → wrong mic selected; check OS settings
"Account not allowed to call X" → Twilio code 21216, can't call your own numbers


WHY MULTIPLE TWILIO ACCOUNTS WEREN'T NEEDED
============================================

You only have ONE Twilio account. Each agent gets their own
"identity" inside that account, which is their user ID in DEBTREX.
Twilio doesn't see them as separate users — but the system uses
the identity to look up which Twilio number to use as their caller
ID. So one Twilio account, many agents, different caller IDs.
