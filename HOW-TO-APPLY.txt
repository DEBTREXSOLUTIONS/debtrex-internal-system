DEBTREX — PAGE ACCESS FIX FOR CUSTOM ROLES
============================================

WHAT THIS FIXES
===============

Several pages redirected custom-role users back to the dashboard
because they used hardcoded role checks like canEditBudget() or
canUseCalculators(). These functions check a hardcoded list of
role names (ceo, owner, manager, etc.) — your custom "system" role
wasn't in those lists, so every page kicked you out.

FIXED PAGES (5 files)
=====================

  app/calculators/page.tsx                  [REPLACE]
  app/performance/page.tsx                  [REPLACE]
  app/performance/assignments/page.tsx      [REPLACE]
  app/budget/page.tsx                       [REPLACE]
  app/budget/allocations/page.tsx           [REPLACE]

Each one now allows access if EITHER:
  - The corresponding section permission is ON
  - OR the user has a built-in role that would normally have access
    (fallback for backward compatibility)


HOW TO APPLY
============

1. Drop the 5 files in (preserve folder structure)
2. git add . && git commit -m "Page access via permissions" && git push
3. Wait for Vercel to deploy (~2 min)
4. Hard refresh: Ctrl + Shift + R


CHECKING WHICH PERMISSIONS YOUR ROLE HAS
=========================================

Visit while signed in:
  https://debtrex-internal-system.vercel.app/api/me/permissions

You'll see a `section_visibility` object. Each value tells you:
  true  = page accessible
  false = page redirects to /

To turn one on:
  - Sign in as CEO
  - Sidebar → Admin → Permissions
  - Find your role's column
  - Toggle the matching permission
  - Save All Changes

ONCE THIS IS APPLIED
======================

For your "system" role to see EVERYTHING, on the Permissions page,
turn ON every toggle in:
  - Section Visibility group  (all 12 toggles)
  - Permissions Admin group   (both toggles)
  - Any feature permissions you want (tasks, pipeline, etc.)

Save All Changes. Hard refresh browser. Sign in again as a system
user. You should now see every section and be able to click into all.
